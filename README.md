Aplikacija za evidenciju opreme za video igre omogućava jednostavno upravljanje bazom podataka koja sadrži podatke o kategoriji, nazivu, proizvođaču I ceni.
Podaci se mogu unositi, menjati I brisati po potrebi, a mogu se i prikazivati u tabeli prema određenim filterima. Baza podataka za WPF C# aplikaciju u Visual Studio okruženju
je kreirana u SQL Server Management Studio.
